## 🛠️ Troubleshooting / Fix Workflow

1. Update Moon Sweepers to 1.0.4 or later before rebuilding around a known fixed machine error.
2. Create a temporary straight belt from one working source toward a known receiver or deposit.
3. Follow a single capsule from the source to the first point where it stops.
4. Check belt direction, connection gaps and the receiving port at that exact junction.
5. For a processing machine, confirm its specific ingredients, power and a free output path.
6. Reattach one splitter or merger at a time; 1.0.4 allows crewmates to add them to existing belts.
7. When a delivery arrives but income does not change, inspect the actual intake and compare a small test payment.

## ❓ FAQ

**Is “Could not pack a capsule” still an official unfixed bug?**  
The specific machine-stall bug was listed as fixed in version 1.0.4. Similar symptoms can still have other causes.

**Should only the host build mergers?**  
That was a launch-era workaround. Shared belt placement was improved in 1.0.3 and 1.0.4.

**What is the first practical test?**  
Trace one capsule over the shortest possible route to isolate the first failure.
